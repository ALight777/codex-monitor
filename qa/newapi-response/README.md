# 0.1.17 NewAPI 网页错误响应处理

## 修复

- 在 JSON 解码前识别 HTML 响应；HTTP 200 返回网页时也明确报错。
- 区分 HTTP 451 访问限制、浏览器安全验证、Cloudflare 1010、重定向、接口未找到及服务器异常。
- 保留 HTTP 状态和失败接口，避免把网页错误当成 PAT 无效；不展示 HTML、重定向查询参数或未经筛选的 JSON。
- 警告卡片支持展开完整诊断文字、选择文字和复制；保持原有 PAT 读取及无登录会话行为。

## 验证

- 使用与应用相同的 URLSession，对问题站点的公开 `/api/status` 与未认证 `/api/user/self` 请求均复现 HTTP 451，响应页面说明站点不向中国大陆地区提供服务。诊断请求未携带 PAT。
- 在包含最新 CodexRadar 与额度修复的 `d7abe4f` 基线之上完成独立构建验证：86 个 Swift 测试和独立回归程序全部通过。
- arm64、amd64 构建成功，本地修复版已安装启动，签名验证通过。
- 本地功能验证版本的安装二进制与构建产物 SHA256 一致。
- 安装前后 NewAPI 账号元数据摘要一致，保留安装时的监测停用状态。
- 原生控件的自动交互验收未完成：独立预览窗口持续触发 ScreenCaptureKit `-3811`，无法取得可操作的窗口。

## 边界

- HTTP 451 的站点访问限制仍然存在；本次修复改善诊断与错误展示，不代表线上余额读取已经恢复。
