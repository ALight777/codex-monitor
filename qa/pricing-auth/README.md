# 0.1.15 模型价格与 NewAPI 认证修复

## 行为

- 默认每日检查 LiteLLM 公开价格 JSON；支持自动开关、更新频率、HTTPS 自定义源、手动刷新。
- 校验标准输入、缓存输入、输出及 272k 上下文档位；不完整价格不导入。失败保留成功缓存和内置兜底。
- Token 明细按模型及单次请求上下文档位聚合，价格变化后直接重估，不重扫所有 JSONL。
- NewAPI 监测只使用 PAT GET /api/user/self 和公开 GET /api/status；不登录、续期或登出，不接收 Cookie，不跟随认证接口重定向。
- 旧账号缺少 PAT 模式标记时暂停请求；编辑时清空密码草稿，保存后才切换为 PAT。原始配置与停用状态保留。

## 验证

- 完整回归脚本通过，包含 53 个 Swift 测试与独立回归可执行程序。覆盖连续三轮 PAT 刷新、旧密码零网络、401 不回退登录、旧配置兼容、凭据不落配置 JSON、更新失败缓存保留、关闭自动更新、重启加载缓存、上下文档位及更新后重估。
- arm64、amd64 的 0.1.15 DMG 构建成功，磁盘镜像完整性校验通过；本机安装启动与签名校验通过。
- 安装二进制与构建产物 SHA256 一致：`d851d34343eb5ba7f8e612faa8a12637f761eeced11e6f3863f803b3ef136bdc`。
- 实际自动同步、点击「立即更新」均成功，导入 80 个模型；重启后成功加载缓存。GPT-6 Astra 已包含在同步数据中。
- 原生设置 UI 已检查：每日自动更新、价格源、成功时间、PAT 空白输入框、可选兼容 ID 均可用。
- 实机验证「修改」更新原账号草稿，不增加账号；取消更改后恢复原名称、配置与启停状态。

## 恢复与边界

- 真实 NewAPI PAT 余额接口未验证；请求契约由官方文档与模拟传输测试验证。
- 旧账号需要重新填写 PAT 并保存后才能恢复监测；原启停配置保持不变，应用不管理或撤销服务器会话。
- 价格是社区维护的数据源，按当前 Standard 费率估算，不还原历史结算，也不包含 Priority/Flex 费率。
