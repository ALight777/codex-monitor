## 最终行为

- 默认总分，可切换庞贝、鹈鹕、糖果，记住选择；支持官网40档（含Terra），不创建不存在的档位组合。
- 庞贝/鹈鹕按100分显示，糖果按对错显示，鹈鹕保留v2/v3规则标记。总分取官网公布值，不把原64题或旧三维度分数混入新数据。
- 公告与评分分别解析、分别保留最近成功缓存；公开读取不携带API Token。每小时/北京时间08:20、14:20检查，失败5分钟重试，失败手动刷新可立即重试。
- 总分费用/耗时仅在三题度量完整时求和；缺失不当作零。费用标记为API等价估算，耗时不含队列和评分；各题来自不同执行轮次。
- 格式变化或首页与分项不一致时明确报错并保留缓存，避免通用“0/34”掩盖真正原因。
- 同时发布本对话10月12日尚未提交的空闲额度刷新、现代Codex CLI路径发现、AppDelegate生命周期及SwiftPM打包路径修复。
