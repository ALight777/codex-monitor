# CodexRadar 三维评分与新闻验收

验收日期：2026-09-08，Asia/Shanghai。

## 功能与数据口径

- Radar 提供综合智能、软件工程能力、视觉空间推理三个维度，默认综合智能，保存上次选择；切换不发起网络请求。
- 软件工程使用官网 `/api/intelligence-efficiency-metrics`，视觉空间使用 `/api/visual-spatial-reasoning`。软件工程兼容 schema 2 的加权题量与 schema 3 的题量；视觉空间展示覆盖题数，不把连续 F1 评分的累计值当作通过题数。
- 综合智能按官网 `compositePoints` / `weightedBothComponentMetric` 算法，匹配同一模型和 effort，以有效题量加权 IQ、平均费用与平均耗时。两个来源缺少任一费用或耗时则该项留空；综合数据时间取两个来源中较早值。
- 原评分说明替换为官网最新公告新闻，可打开来源原文；完整文本在原有滚动区域自然换行，不执行网页脚本。
- 软件工程、视觉空间、新闻分别缓存。单个来源失败时保留该来源最后有效数据并提示，其他来源正常更新；综合页标明存在未更新的组成数据。仍按每小时及北京时间 08:20 / 14:20 自动检查，失败 5 分钟重试。
- 可选 Token 仅发送至原授权接口，用于补充套餐额度；三个评分维度与新闻都使用公开来源。
