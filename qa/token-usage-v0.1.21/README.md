# v0.1.21 用量统计修复验收

## 修复内容

- 完整索引会话及归档日志，不再将历史统计限制为文件末尾或最近若干个对话。
- 支持 Codex 自动生成的 `.jsonl.zst`；数据库仍引用 `.jsonl` 时可定位压缩原件。
- 内置 Zstandard 1.5.7 解码器，流式解压并校验，不依赖外部命令，也不生成用户日志副本。
- 同一对话的多个文件合并统计，排除跨文件重放、重复累计快照及可识别的继承历史。
- 未压缩日志增量读取；压缩日志按文件签名缓存。替换、截断、删除和取消均处理缓存失效。
- 今日按本机自然日统计；24 小时、7 天、30 天使用滚动窗口。模型切换及费用明细继续按请求归属。
- 缺失、不可读或损坏的日志明确提示，损坏压缩文件不会发布部分结果，也不会将生命周期累计值记到今日。
- 限制 Foundation 临时对象生命周期，避免批量扫描保留整个数据集。

本版本同时保留已完成的 Spark 额度入口清理；标准 Codex 额度解析不受 Spark 数据干扰。

## 验证

- 116 项 Swift 测试及独立回归程序通过。
- 合成测试覆盖大文件、UTF-8 / 块 / 多帧边界、压缩前后副本共存、归档路径、完整性错误、增量与缓存失效、日期边界和子代理历史。
- 本机完整数据集经独立 zstd CLI 与 Python JSON 解码，对照应用内置解码器；四个时间窗口结果一致。
- 未变化的日志复用内存索引，无需再次读取内容。
- arm64 / x86_64 构建、两个 DMG 完整性、应用签名及安装版本一致性检查通过。
- 本机 Apple Silicon 安装版界面已核验；Intel 未做实机 UI 验证。

原始用户日志、对话标题、路径及逐对话审计数据不随仓库或发行版发布。
